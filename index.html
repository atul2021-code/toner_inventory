Pushing to GitHub Pages

Click "Download toner_inventory.zip" in the top banner. Then follow either option below to publish the site to your GitHub repository:

Option 1: Drag & Drop via GitHub Website (Easiest)

  1. Unzip toner_inventory.zip on your computer.
  2. Go to your repository: github.com/atul2021-code/toner_inventory
  3. Click Add file → Upload files.
  4. Drag in all extracted files (index.html, README.md, .nojekyll, .gitignore, LICENSE).
  5. Click Commit changes.

Option 2: Activate GitHub Pages

  1. Go to the Settings tab in your repository.
  2. Click Pages in the left sidebar.
  3. Under Build and deployment > Branch, select main and folder / (root), then click Save.
  4. Within 60 seconds, your site is live at: https://atul2021-code.github.io/toner_inventory/

Clear All Records?

This will remove all saved toner stock, printers, and movement history from this browser.
